# WalletWatch Project: https://walletwatch-dashboard.netlify.app/

## Overview
WalletWatch is a simple web application designed to help users track their income and expenses throughout the year. The application features a user-friendly interface with two main tabs: "Data" for inputting financial information and "Chart" for visualizing that data through bar charts.

## Project Structure
```
Bucks2Bar
├── index.html          # Main HTML document for the application
├── css
│   └── styles.css      # Custom styles for the application
├── js
│   ├── app.js          # Main JavaScript entry point
│   ├── data.js         # Manages income and expense data input
│   └── chart.js        # Renders the bar chart using the chart library
├── lib
│   ├── bootstrap.min.css # Minified CSS for Bootstrap
│   ├── bootstrap.min.js  # Minified JavaScript for Bootstrap
│   └── chart.min.js      # Minified JavaScript for the chart library
└── README.md           # Documentation for the project
```

## Features
- Input fields for tracking income and expenses for each month from January to December.
- Tabbed interface for easy navigation between data input and chart visualization.
- Responsive design using Bootstrap for a modern look and feel.
- Bar chart visualization of income and expenses using a charting library.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser to view the application.
3. Ensure that all necessary files are included in the project structure.

## Usage Guidelines
- Navigate to the "Data" tab to enter your income and expenses for each month.
- Switch to the "Chart" tab to view a visual representation of your financial data.
- Use the input fields to update your data as needed, and the chart will reflect the changes automatically.
